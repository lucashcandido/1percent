# 1Percent-Widget für Übersicht

Zeigt auf dem Mac-Schreibtisch: Monat (Einnahmen, Ausgaben, Saldo, Ersparnis, offene Fixkosten), ToDos von heute, die nächsten Important Dates, das letzte Training und das Wasser von heute. Ein Klick öffnet 1Percent. Aktualisiert sich alle 5 Minuten.

1. [Übersicht](https://tracesof.net/uebersicht/) installieren und starten.
2. Menüleisten-Symbol → *Open Widgets Folder* → den Ordner `1percent.widget` hineinlegen.
3. Im Ordner `config.sh.example` nach `config.sh` kopieren und Repo + Token eintragen
   (Fine-grained Token, nur das Daten-Repo, *Contents: Read-only*).
4. Fertig – das Widget erscheint oben rechts. Position ändern: in `index.jsx` bei `top`/`right`.
